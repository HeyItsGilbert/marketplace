# architecture-decisions retirement

The `architecture-decisions` plugin was removed from this marketplace on 2026-08-31. The marketplace no longer publishes `/adr` or `/rfc`, and it does not provide a tombstone or a compatibility release.

For ongoing ADR workflow guidance, install the official `mattpocock-skills` plugin with `/plugin install mattpocock-skills`, then run its setup workflow once in each repository before using its `domain-modeling` or `grill-with-docs` workflows to maintain ADRs inline. This is not a one-for-one replacement for `/adr`.

RFC authoring is discontinued. No replacement is provided by this redirect.

Claude Code plugin installations are cached copies. Users who already installed `architecture-decisions` receive no automatic migration notice; they must remove the installed plugin and choose the replacement workflow themselves.
