# MARP delivery checks

Use this reference only for a slide that uses the named feature.

- **Images:** Verify each image's rendered size and crop leave the intended focal content visible. For background images, verify the rendered background still supports the slide's first-read element and text contrast.
- **Speaker notes:** Verify speaker prose is in HTML comments associated with its slide, while visible slide text remains phrases or keywords.
- **Pagination:** Verify expected page numbering is enabled by the presentation's existing frontmatter or local directives and is legible without overlapping content.
- **Code:** Verify the rendered block is readable at presentation size, has no clipped or overflowing lines, and can be scanned in its intended order.
- **Slide breaks:** Verify each `---` horizontal rule separates intended slides and that no intended slide boundary is missing.
- **Frontmatter:** Verify the presentation's existing required frontmatter is present and accepted by its renderer.
