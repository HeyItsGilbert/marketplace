# Open Graph and social metadata

Load this reference only when publishing page metadata. Replace placeholders with the canonical page and absolute HTTPS image URLs.

```html
<meta property="og:title" content="Title" />
<meta property="og:description" content="Description" />
<meta property="og:image" content="https://example.com/og-image.png" />
<meta property="og:url" content="https://example.com/page" />
<meta property="og:type" content="article" />
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Title" />
<meta name="twitter:description" content="Description" />
<meta name="twitter:image" content="https://example.com/og-image.png" />
```

Validate the final URL and preview using the relevant platform's current sharing inspector.
